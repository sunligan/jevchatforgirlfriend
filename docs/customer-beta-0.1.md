# 客服 Beta 0.1

日期：2026-09-24

## 目标

在现有聊天副驾基础上，先验证“抖音固定话术客服 + 微信线索分发队列”的最小闭环。

## 已实现

### 抖音 Beta 适配

- 包名：`com.ss.android.ugc.aweme` 与 `com.ss.android.ugc.aweme.lite`。
- 使用保守无障碍启发式：当前页面必须有可编辑输入框，并能读到消息区域文字；无法确认时不自动发送。
- 会话标题、最近消息和“我/对方”先转为统一 `ChatSnapshot`。
- 固定回复状态机：
  - 两句都没出现：计划发送第 1 句、第 2 句；
  - 检测到第 1 句已经出现：只计划第 2 句；
  - 两句都出现：不重复回复；
  - 话术为空：提示人工配置。

### 自动发送 / 手动确认

- 设置中有“固定话术自动发送”开关，默认关闭。
- 关闭：显示每句固定话术，可分别复制或填入；发送由人确认。
- 开启：只对固定话术逐句填入，并尝试点击可明确识别的“发送”按钮。
- 找不到唯一发送按钮、识别到多个发送按钮或会话状态不确定：停止自动发送，只保留已填入内容并提示人工处理。
- 不使用模型自由生成内容自动发送。

### 联系方式线索

- 识别手机号、常见微信号格式、以及“加微信 / vx / weixin / 微信聊”等暗示。
- 具体手机号/微信号：保存到 App 私有目录 `filesDir/customer/leads.json`。
- 仅有加微信暗示：不发送敏感规避话术，发提示音并提示人工处理。
- 每条线索附带：来源会话、分类、目标微信群、原始文本、创建时间、是否已处理。

### 微信分发队列

- 设置里配置默认分类和默认目标群。
- 线索页面展示待处理记录。
- 一键复制整理好的分发文本，用户打开目标微信群后粘贴并确认发送。
- Beta 0.1 不在未知微信版本上自动点击群聊发送；防止同名群、错群和窗口切换导致误发。

## 当前边界

- 本版不是“遍历整个抖音会话列表并持续无人值守”的最终版本，先以当前打开会话验证闭环。
- 抖音不同版本节点结构差异较大，实际适配必须在目标手机和目标版本上验证。
- 线索分类目前来自设置中的一个默认分类；后续可以做多分类映射和群映射表。
- 微信分发先队列/复制/填入，最终发送由人工确认。
- 自动发送开关只对固定话术生效；模型判断/生成结果不会绕过人工确认自动发送。

## 测试重点

1. 关闭自动发送：抖音当前会话收到新消息后，面板出现固定话术，每句可单独填入。
2. 开启自动发送：只配置测试话术，确认两句按顺序发送；若第一句已在会话里出现，只发送第二句。
3. 给出手机号、微信号、或“加微信”暗示，检查提示音和线索队列。
4. 打开“客服线索 / 微信分发队列”，复制分发文本到测试微信群，手动发送并标记已处理。
5. 切换到普通微信聊天：客服 Beta 不应接管普通微信模型副驾流程。
6. 关闭客服 Beta：原来的个人聊天副驾逻辑继续工作。
